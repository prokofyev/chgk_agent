## Why

Сейчас веб-интерфейс работает как браузер похожих вопросов: пользователь видит карточки совпадений с процентами, бейджи источников и список «опирается на найденные вопросы». Но ценность сервиса — не список, а ответ на исходный вопрос X. Показ промежуточной выдачи отвлекает, а требование «опирайся только на эти данные» мешает отвечать, когда похожих вопросов не нашлось: сервис вместо ответа сообщает, что надёжный ответ сформировать нельзя.

## What Changes

- **BREAKING**: веб-интерфейс перестаёт показывать похожие вопросы, оценки, источники и статусы. На странице остаются поле ввода, кнопка «Ответить» и сгенерированный ответ.
- **BREAKING**: заголовок интерфейса меняется с «Поиск вопросов ЧГК» на «ЧГК знаток».
- С формы убираются поля «Число результатов», «Минимальный порог» и чекбокс «Сгенерировать ответ»; значения фиксируются (`limit=20`, `min_score=0.85` по умолчанию, ответ генерируется всегда).
- Порог `min_score` по умолчанию поднимается с `0.0` до `0.85` и из «отсечки выдачи» становится «фильтром контекста».
- **BREAKING**: генерация ответа выполняется всегда, в том числе когда похожих вопросов не нашлось. Промпт становится ролевым: модель отвечает на вопрос X как игрок ЧГК, а найденные вопросы передаются как необязательный контекст.
- Кнопка «Ответить» заблокирована, пока описание короче трёх символов.
- При сбое поиска или генерации, а также при запросе в обход блокировки, интерфейс отвечает «Не знаю». Технические детали (`request_id`, текст ошибки) на экран не выводятся.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `search-web-ui`: форма теряет параметры поиска, страница перестаёт отображать состояние, источники и список совпадений, остаётся только ответ; меняется заголовок интерфейса; добавляется блокировка кнопки и ответ «Не знаю» при неудаче.
- `question-search`: формирование ответа на основе найденных вопросов превращается в безусловную генерацию ответа на исходный вопрос с необязательным контекстом; сценарий отсутствия подтверждающих совпадений заменяется генерацией с пустым контекстом; значение `min_score` по умолчанию поднимается до `0.85`.

## Impact

- `src/chgk_agent/ui/app.py` — переписывается разметка страницы и обработчик кнопки.
- `src/chgk_agent/ui/view.py` — модель экрана сокращается до состояния и ответа; логика валидации сохраняется, отображение совпадений и источников удаляется.
- `src/chgk_agent/search/nodes.py` — промпт генерации, условие запуска генерации, поведение при отсутствии совпадений.
- `src/chgk_agent/config.py` — значение `SearchSettings.min_score` по умолчанию.
- `tests/test_ui.py`, `tests/test_search_graph.py`, `tests/test_end_to_end.py` — обновление тестов формы, состояний и генерации.
- `README.md` — описание интерфейса и раздела о генерации ответа.
- API `/search` не меняется: `matches` по-прежнему возвращаются для внешних клиентов и набора качества поиска; UI просто перестаёт их показывать.
